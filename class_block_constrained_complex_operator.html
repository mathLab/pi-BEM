Detailed Description

template<class VEC, class MATRIX>
class BlockConstrainedComplexOperator< VEC, MATRIX >

Constrained complex operator using block 0 for real and block 1 for imaginary. MATRIX supplies this_cpu_set and the four-vector vmult overload. Both constraints use unshifted indices and must constrain the same rows. Objects referenced by the constructor must outlive this adapter. Invoke vmult() and distribute_rhs() collectively on comm with compatible distributed layouts.
