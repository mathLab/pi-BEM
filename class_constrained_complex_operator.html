Detailed Description

template<class VEC, class MATRIX>
class ConstrainedComplexOperator< VEC, MATRIX >

Constrained complex operator using a flat [real, imaginary] vector of size 2N. MATRIX supplies this_cpu_set and vmult(dst_re,dst_im,src_re,src_im). Both constraint objects use unshifted N-vector indices and must constrain the same rows. Referenced matrix/constraints must outlive this object. Calls are collective on comm; mutable caches prevent simultaneous vmult calls on one instance. distribute_rhs() replaces constrained entries with inhomogeneities.
