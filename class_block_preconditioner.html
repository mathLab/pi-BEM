Detailed Description

template<class PreconditionerType>
class BlockPreconditioner< PreconditionerType >

Apply one referenced preconditioner independently to every real block. vmult() and Tvmult() require compatible source/destination block layouts. The underlying preconditioner must outlive this adapter.
