Compute cellwise errors with hp mappings/quadratures and material-selected exact solutions. Function pointers are non-owning and must match the finite element component count. Missing material IDs and non-owned cells contribute zero. The output is resized to the number of active cells; global norm reduction remains the caller's responsibility. Uses deal.II internal helpers.

Single-mapping/quadrature wrapper for material-selected cellwise errors. exact_solutions is keyed by cell material_id (not manifold_id). Function pointers must remain valid throughout the call; absent IDs contribute zero. Apply VectorTools::compute_global_error() for a global norm. Weight and exponent follow VectorTools::integrate_difference() conventions.
